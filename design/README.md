# Hounain Display

Original geometric lettering drawn for Ali Hounain's portfolio, informed by the supplied title and poster references. It is not an identification or extraction of the television show's font.

The WOFF2 contains A, H, I, L, N, O, U, period, and space: the characters required for ALI HOUNAIN. Keep its use scoped to the name; Anton remains the general heading face and Space Grotesk the body face. The matching A animation uses the same geometry as an inline SVG.

Opening runs for about 2.3 seconds once per session on a visit without an anchor. Play intro replays it; Skip intro and Escape dismiss it. Reduced-motion preference suppresses it. Without JavaScript the portfolio remains visible and the opening stays hidden.

The font construction source is make_display.py (requires fonttools and brotli); set its output directory for your local checkout before running it.

Current active name font: user-supplied Velvet Omen Grotesk. WOFF2 converted from the supplied TTF; monogram and opening A use its original glyph outline. Hounain Display remains available as an earlier option.
